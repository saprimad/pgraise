# PGRaise

A sleek, responsive postgraduate monitoring dashboard with a UiTM-inspired purple and gold theme. This is an independent concept, not an official university system.

## Run locally

```sh
python3 -m http.server 5173 --directory dist
```

Open http://localhost:5173.

## Features

- Student directory with search and status filters
- Student profiles with research titles and supervisors
- Editable milestone progression and attention status
- Add postgraduate records with duplicate ID validation
- Programme reports, supervisor summaries and CSV export
- Responsive layouts and keyboard-accessible controls

The initial eight student records and activity entries are fictional examples. Changes persist in browser localStorage; this prototype does not include authentication, a shared database or real university data. Upcoming events are illustrative October 2026 entries. External Google Fonts are optional; system fonts remain available as a fallback.
